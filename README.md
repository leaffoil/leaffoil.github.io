# Developer Portfolio

A responsive static portfolio built with HTML, CSS, and JavaScript. It can be hosted free with GitHub Pages; no local server or paid hosting is required.

## Before publishing
1. Update the name/brand `leaffoil` if you want a different public identity.
2. Replace `your.email@example.com` in `index.html` with your real contact email.
3. Check the project descriptions and links. The Blackjack link currently points to `https://github.com/leaffoil/priv`; change it if your project is in another repository.
4. Update the skills and project cards as your experience grows.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `leaffoil.github.io` (replace `leaffoil` with your GitHub username if different).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root. Do not upload the ZIP file itself.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. Your public site should appear at `https://leaffoil.github.io/`.

If you use a repository with another name instead, the URL will usually be `https://leaffoil.github.io/repository-name/`.

## Local preview (optional)
Open `index.html` in a browser. This is optional; GitHub Pages serves the published site online.
